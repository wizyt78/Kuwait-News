# AL QABAS DIGITAL — GitHub Pages

Upload these files to the repository root:

- index.html
- styles.css
- script.js
- README.md
- assets/hero-image.jpg
- assets/comments/comment-1.jpg
- assets/comments/comment-2.jpg

## Language
Arabic is the first/default language. The visitor can switch to English, and the selection is remembered in the browser. All visible copy is driven by the `T` translation object in `script.js`.

## Images
The page supports local image selection and immediate preview:
- Main feature image: `Choose report image`
- Each comment image: `Replace photo`

A browser-selected image is only a local preview on that device. To permanently change the GitHub site, replace the corresponding image file in the repository and keep the same filename/path.

**Important:** Do not rename a JPEG/PNG file to `.svg`. The file extension must match the actual image format.

## WhatsApp
The form opens a direct WhatsApp conversation to the configured number in `script.js`.

Use truthful, verifiable article content, authorized branding/images, genuine testimonials, and an accurate support/availability status.
