# Al Qabas Digital — Safe Demo

This is a polished, responsive news-style front-end demo.

IMPORTANT:
- It is intentionally labeled as FICTIONAL DEMO.
- It does not impersonate a real government announcement or a real person.
- It does not make investment, banking, trading, or guaranteed-income claims.
- The form is demo-only and should not be used to collect sensitive information.

## GitHub Pages
1. Create a GitHub repository.
2. Upload the contents of this ZIP (index.html, styles.css, script.js, assets/).
3. In GitHub: Settings → Pages → Deploy from branch → main → /root.
4. Open the generated Pages URL.

## Replace the hero image
Replace `assets/hero-image.svg` with your own properly licensed image and update the `<img src>` in `index.html` if the filename changes.

## WhatsApp
Open `script.js` and replace:
`const waNumber="15551234567";`
with a WhatsApp number you own or have permission to use, including country code and no `+`, spaces, or dashes.

The page opens a pre-filled demo message only. Do not use it to request passwords, card numbers, banking credentials, identity numbers, or other sensitive information.
